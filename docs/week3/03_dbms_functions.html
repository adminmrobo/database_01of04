DBMS의 정의와 주요 기능Definition & Functions

한 문장으로: 파일 시스템의 데이터 중복과 데이터 종속 문제를 해결하는 시스템입니다.

1정의
데이터베이스 관리 시스템(DBMS) = 파일 시스템의 데이터 중복과 데이터 종속 문제를 해결하는 시스템

응용 프로그램은 DBMS에만 요청하고, 실제 값은 통합 저장소 한 곳에만 있습니다.

2주요 기능 — 정의·조작·제어
기능하는 일언어예
정의데이터 구조를 만들고 바꾼다DDLCREATE TABLE, ALTER TABLE
조작값을 넣고, 찾고, 고치고, 지운다DMLINSERT, SELECT, UPDATE, DELETE
제어권한·무결성·동시성·회복을 관리한다DCLGRANT, REVOKE, COMMIT, ROLLBACK
세 기능은 순서가 있습니다 먼저 정의로 그릇을 만들고, 조작으로 값을 다루며, 제어로 안전하게 지킵니다. 순서를 바꾸면 "테이블이 없습니다" 오류를 만납니다.
3장점 8가지 · 단점 3가지
DBMS의 장점
  • 데이터의 중복을 통제할 수 있음
  • 데이터의 독립성을 확보
  • 데이터를 동시에 공유
  • 데이터의 보안이 향상
  • 데이터의 무결성을 유지
  • 표준화
  • 장애 발생 시 회복이 가능
  • 응용 프로그램 개발 비용 절감
DBMS의 단점
  • 비용의 문제 — 소프트웨어·서버·인력
  • 백업과 회복 방법이 복잡
  • 중앙관리로 인한 취약점 — 한 곳이 멈추면 전체가 멈춤

보충 자료에서 더한 실무적 단점: DB 전문 인력(DBA) 확보·유지의 어려움. 그럼에도 대부분의 기업에서 장점이 단점을 상회해 DBMS를 도입합니다.
